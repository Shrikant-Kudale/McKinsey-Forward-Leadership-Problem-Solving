# McKinsey-Forward-Leadership-Problem-Solving

A 31-day learning sprint (August 2026) that follows the ten sessions of the McKinsey Forward Learning Program. Each day has a framework guide, a worked case study, an executive playbook, a reusable template, a dataset and a Python decision-support tool.

> This is an independent self-study repository. It is not an official McKinsey & Company product and reproduces no proprietary program materials.

## Using the commit pipeline
`backdate_commit_pipeline.py` creates a git history with one run: it initialises the repository on `main`, asks for a minimum and maximum number of commits per day, and writes commits for each day folder with author and committer dates on the matching August 2026 date (09:15 to 22:45 IST). Those commits are backdated, which git and GitHub record as authored dates. After it finishes, add your remote and push:

```
git remote add origin <your-repository-url>
git push -u origin main
```
