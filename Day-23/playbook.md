# Executive Playbook: Generative AI & Human-in-the-Loop Workflows

## Purpose
Give a repeatable, 60-minute routine for **generative AI human-in-the-loop** that you can run on any project.

## Core idea
Generative AI accelerates synthesis, brainstorming and red-teaming, but it can hallucinate and invite automation bias. Reliable workflows define the task, supply context, require sources, and place a human review gate before decisions.

## Procedure
### Step 1
Define the task, audience and output format in the prompt.

**Deliverable:** one written paragraph or table that proves this step is complete.

### Step 2
Supply context and constraints; ask for assumptions explicitly.

**Deliverable:** one written paragraph or table that proves this step is complete.

### Step 3
Require citations and verify the top claims.

**Deliverable:** one written paragraph or table that proves this step is complete.

### Step 4
Use AI to red-team your argument for risks and counterexamples.

**Deliverable:** one written paragraph or table that proves this step is complete.

### Step 5
Keep a human decision gate with a log of overrides.

**Deliverable:** one written paragraph or table that proves this step is complete.

## Watch-outs
- Accepting fluent text as verified fact
- Sharing confidential data with unapproved tools

## Worked example
**Analyst uses an LLM to draft a market synthesis.** An analyst prompted with context and required sources, then verified five key claims; two figures were wrong and were corrected. A red-team prompt surfaced a competitor risk that was missing, and the override log showed the model was useful but never authoritative.

## Quality bar
- My prompts state task, context and format
- I verified key claims
- I used AI to challenge my view
- A human gate exists before decisions
