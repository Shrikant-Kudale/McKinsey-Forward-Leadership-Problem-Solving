# Executive Playbook: Agile Cadences, Delegation & Accountability Frameworks

## Purpose
Give a repeatable, 60-minute routine for **RACI, agile cadence and delegation** that you can run on any project.

## Core idea
RACI (Responsible, Accountable, Consulted, Informed) and RAPID clarify decision rights. A task must have exactly one accountable owner. Agile retrospectives and delegation checklists keep accountability visible and learning continuous.

## Procedure
### Step 1
List tasks and decisions for the project.

**Deliverable:** one written paragraph or table that proves this step is complete.

### Step 2
Assign RACI letters; ensure exactly one A per task.

**Deliverable:** one written paragraph or table that proves this step is complete.

### Step 3
Cap consulted roles at three to avoid slow decisions.

**Deliverable:** one written paragraph or table that proves this step is complete.

### Step 4
Run a sprint retrospective: keep, stop, start.

**Deliverable:** one written paragraph or table that proves this step is complete.

### Step 5
Delegate using a checklist: outcome, constraints, authority, check-in.

**Deliverable:** one written paragraph or table that proves this step is complete.

## Watch-outs
- Shared accountability meaning no accountability
- Too many consulted parties slowing decisions

## Worked example
**Cross-functional feature launch.** A launch matrix showed two accountable owners for test sign-off and none for analytics instrumentation. The validator surfaced both gaps before kickoff, and a go/no-go decision with four consulted roles was streamlined.

## Quality bar
- Every task has exactly one A
- No role is overloaded as R
- Retros produce one change per sprint
- Delegations state outcome, constraints and authority
