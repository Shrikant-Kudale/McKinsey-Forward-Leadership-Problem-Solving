# Day 21 (2026-08-21): Agile Cadences, Delegation & Accountability Frameworks

**McKinsey Forward alignment:** Session 7 - High-Performing Teams & Collaboration

## Framework breakdown
RACI (Responsible, Accountable, Consulted, Informed) and RAPID clarify decision rights. A task must have exactly one accountable owner. Agile retrospectives and delegation checklists keep accountability visible and learning continuous.

## Step-by-step methodology
1. List tasks and decisions for the project.
2. Assign RACI letters; ensure exactly one A per task.
3. Cap consulted roles at three to avoid slow decisions.
4. Run a sprint retrospective: keep, stop, start.
5. Delegate using a checklist: outcome, constraints, authority, check-in.

## Real-world case study: Cross-functional feature launch
A launch matrix showed two accountable owners for test sign-off and none for analytics instrumentation. The validator surfaced both gaps before kickoff, and a go/no-go decision with four consulted roles was streamlined.

## Common pitfalls
- Shared accountability meaning no accountability
- Too many consulted parties slowing decisions
