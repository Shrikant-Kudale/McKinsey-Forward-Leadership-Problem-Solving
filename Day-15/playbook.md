# Executive Playbook: Executive Data Storytelling & High-Impact Visuals

## Purpose
Give a repeatable, 60-minute routine for **data storytelling and visuals** that you can run on any project.

## Core idea
Choose visuals by message: bars for comparisons, lines for trends, stacked bars for composition, scatter for relationships. Every chart carries an action title, a labelled unit and one highlighted insight.

## Procedure
### Step 1
Write the message the chart must prove.

**Deliverable:** one written paragraph or table that proves this step is complete.

### Step 2
Pick the chart type: comparison, trend, composition or relationship.

**Deliverable:** one written paragraph or table that proves this step is complete.

### Step 3
Remove clutter: gridlines, legends and decimals that do not help.

**Deliverable:** one written paragraph or table that proves this step is complete.

### Step 4
Highlight the single data point that proves the title.

**Deliverable:** one written paragraph or table that proves this step is complete.

### Step 5
Generate SVG charts from the spec file and review them.

**Deliverable:** one written paragraph or table that proves this step is complete.

## Watch-outs
- Pie charts for many categories
- Truncated axes that exaggerate differences

## Worked example
**Three charts for a retail board pack.** The board pack used three charts: contribution margin by channel (bar), repeat purchase by month (line), and outage minutes by cause (bar). The chart generator turned a JSON spec into clean SVGs in seconds, so edits to titles and values took minutes.

## Quality bar
- Each chart proves its action title
- I chose the chart type by message
- Units and sources are labelled
- I removed non-essential decoration
