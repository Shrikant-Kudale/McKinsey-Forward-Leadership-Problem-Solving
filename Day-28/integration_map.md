| From | To | How it reinforces |

| 1 Adaptability | 2 Defining | Growth mindset keeps you questioning the first framing |
| 2 Defining | 3 Structuring | A sharp question determines the tree |
| 3 Structuring | 4 Analysis | Tree branches become analyses and workplans |
| 4 Analysis | 5 Communicating | Synthesis ladder feeds the pyramid |

## Weakest-link rule
Identify the lowest session score in the scorer. Invest there first: a weak link caps the value of every downstream pillar.
