# Executive Playbook: Connecting All 10 Forward Pillars

## Purpose
Give a repeatable, 60-minute routine for **integrating the ten pillars** that you can run on any project.

## Core idea
Problem solving, communication, influence, teamwork, digital fluency and resilience reinforce one another: a well-defined problem (Session 2) makes a structured tree (3) and a focused analysis (4) possible, which supports a pyramid-style recommendation (5) that stakeholders (6) can act on with a team (7), augmented by digital tools (8), sustained by resilience (9).

## Procedure
### Step 1
Score yourself on each of the ten sessions.

**Deliverable:** one written paragraph or table that proves this step is complete.

### Step 2
Draw the dependency map between pillars.

**Deliverable:** one written paragraph or table that proves this step is complete.

### Step 3
Identify the weakest link that constrains the others.

**Deliverable:** one written paragraph or table that proves this step is complete.

### Step 4
Pick one integrated practice, such as running a mini case weekly.

**Deliverable:** one written paragraph or table that proves this step is complete.

### Step 5
Schedule a monthly integration review.

**Deliverable:** one written paragraph or table that proves this step is complete.

## Watch-outs
- Optimising one pillar while another is the bottleneck
- Learning each pillar in isolation

## Worked example
**Mini-case drill that chains all pillars.** A junior team ran a weekly one-hour drill: frame the problem, build a tree, analyse, write a pyramid memo, pre-wire, and debrief. Over eight weeks, memo quality scores rose and stakeholder rework fell by half.

## Quality bar
- I scored all ten sessions
- I know my weakest link
- I have a weekly integrated practice
- I scheduled a monthly review
