# Day 12 (2026-08-12): Synthesizing Insights: From Raw Findings to So What

**McKinsey Forward alignment:** Session 4 - Data-Driven Analysis & Synthesis

## Framework breakdown
Synthesis climbs a ladder: Fact (what the data says), Finding (pattern across facts), Implication (what it means for the client) and Recommendation (what to do). Each rung must be traceable to the one below.

## Step-by-step methodology
1. List the raw facts with sources.
2. Group facts into findings with a one-line pattern statement.
3. Write the implication for the client: so what?
4. Draft recommendations with owner, timing and expected impact.
5. Trace each recommendation back to facts to check the logic.

## Real-world case study: Logistics firm sees late deliveries cluster in two depots
Facts: 62 percent of late deliveries originate from two of nine depots, and both run manual dock scheduling. Finding: scheduling method predicts lateness. Implication: 1.8M in annual penalties are avoidable. Recommendation: pilot automated scheduling in both depots within one quarter.

## Common pitfalls
- Presenting findings as if they were recommendations
- Skipping the implication rung
