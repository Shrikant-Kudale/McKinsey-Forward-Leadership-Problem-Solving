# Executive Playbook: Synthesizing Insights: From Raw Findings to So What

## Purpose
Give a repeatable, 60-minute routine for **synthesis ladder** that you can run on any project.

## Core idea
Synthesis climbs a ladder: Fact (what the data says), Finding (pattern across facts), Implication (what it means for the client) and Recommendation (what to do). Each rung must be traceable to the one below.

## Procedure
### Step 1
List the raw facts with sources.

**Deliverable:** one written paragraph or table that proves this step is complete.

### Step 2
Group facts into findings with a one-line pattern statement.

**Deliverable:** one written paragraph or table that proves this step is complete.

### Step 3
Write the implication for the client: so what?

**Deliverable:** one written paragraph or table that proves this step is complete.

### Step 4
Draft recommendations with owner, timing and expected impact.

**Deliverable:** one written paragraph or table that proves this step is complete.

### Step 5
Trace each recommendation back to facts to check the logic.

**Deliverable:** one written paragraph or table that proves this step is complete.

## Watch-outs
- Presenting findings as if they were recommendations
- Skipping the implication rung

## Worked example
**Logistics firm sees late deliveries cluster in two depots.** Facts: 62 percent of late deliveries originate from two of nine depots, and both run manual dock scheduling. Finding: scheduling method predicts lateness. Implication: 1.8M in annual penalties are avoidable. Recommendation: pilot automated scheduling in both depots within one quarter.

## Quality bar
- Each finding cites at least two facts
- Implications are client-specific
- Recommendations have owner, timing and impact
- I can trace any recommendation back to facts
