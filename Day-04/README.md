# Day 04 (2026-08-04): Deconstructing Ambiguous Business Challenges

**McKinsey Forward alignment:** Session 2 - Defining the Problem

## Framework breakdown
A well-framed problem separates symptoms (what we observe) from root causes (why it happens). The Situation-Complication-Question framing anchors the context everyone agrees on, the change that creates tension, and the single question the work must answer.

## Step-by-step methodology
1. List observed symptoms and tag each as fact or assumption.
2. Write the Situation as uncontested context.
3. Write the Complication: what changed or broke.
4. Write the Key Question in one sentence that a decision-maker could answer.
5. Complete the Problem Statement Worksheet and test it with the sponsor.

## Real-world case study: Online marketplace sees repeat purchases decline
The CEO asked how to boost marketing spend because repeat purchases fell. SCQ framing showed the situation (growth through acquisition), the complication (repeat rate fell from 34 to 27 percent in two quarters) and a different question: why are first-time buyers not coming back? Marketing spend was a premature solution.

## Common pitfalls
- Writing the solution inside the question
- A Situation that contains opinions
