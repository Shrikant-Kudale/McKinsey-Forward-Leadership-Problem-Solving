# Executive Playbook: Full Business Case Simulation: Retail Margin & Digital Turnaround

## Purpose
Give a repeatable, 60-minute routine for **retail margin turnaround simulation** that you can run on any project.

## Core idea
The capstone case walks the full consulting arc: SCQ framing, MECE issue tree, hypothesis-driven analysis, financial model and a Pyramid Principle board memo. A regional retailer must lift thin margins while digital channels grow.

## Procedure
### Step 1
Frame the problem with SCQ and a SMART statement.

**Deliverable:** one written paragraph or table that proves this step is complete.

### Step 2
Build a MECE profit tree by channel and cost type.

**Deliverable:** one written paragraph or table that proves this step is complete.

### Step 3
Run the driver simulator to rank levers.

**Deliverable:** one written paragraph or table that proves this step is complete.

### Step 4
Pressure-test the numbers with sanity checks.

**Deliverable:** one written paragraph or table that proves this step is complete.

### Step 5
Write the board memo with the answer first.

**Deliverable:** one written paragraph or table that proves this step is complete.

## Watch-outs
- Recommending a digital build-out without checking channel margins
- Presenting levers without quantifying them

## Worked example
**Regional retailer: 85.8M revenue, 1.3 percent operating margin.** In-store, online and click-and-collect channels produce 18.3M contribution against 17.2M fixed costs, leaving 1.1M profit. Online contributes the lowest margin per transaction because fulfilment cost is high. Cost levers dominate: a 5 percent variable-cost programme is worth about 3.4M versus 0.4M from mix shift.

## Quality bar
- My SCQ and SMART statement are written
- My tree reconciles to 1.1M profit
- I ranked levers with the simulator
- The board memo opens with the answer
